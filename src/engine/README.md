# Calculation engine

사주결의 계산 엔진은 **달력 계산**과 **해석 문장**을 분리합니다.

현재 확정한 1차 원칙:

- 년주: 입춘의 실제 절입 시각을 경계로 전환
- 월주: 입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한의 실제 절입 시각을 경계로 전환
- 일주: 60갑자 순환을 독립 계산하고 한국천문연구원 일진 자료와 golden test로 대조
- 시지: 보정이 끝난 시각을 기준으로 자시 23:00~00:59부터 2시간 단위
- 십성: 일간과 다른 천간의 오행 생극 및 음양 관계만으로 결정
- 오행 숫자는 우선 '천간 4 + 지지 4의 표면 구성'만 표시하며 신강·신약 점수로 사용하지 않음
- 출생시간 미상은 시주를 만들지 않음

아직 단일 정답으로 고정하지 않는 항목:

- 23:00~23:59 일주 변경(자초/자정 경계)
- 출생지 경도에 따른 태양시 보정
- 균시차 적용
- 역사적 서머타임 및 표준시 변경의 사용자 표시 방식

이 항목들은 계산 엔진 내부에서 숨겨서 결정하지 않고 명시적인 정책/옵션으로 분리합니다.

> 실제 서비스 연결 전에는 절입 경계, 23시대, 역사적 표준시·서머타임 케이스를 별도 golden test로 통과해야 합니다.
