# Calculation engine

사주결의 계산 엔진은 **법정 시각 → 절기/간지 계산 → 해석 콘텐츠**를 분리합니다.

## 현재 구현된 1차 원칙

- 년주: 입춘의 실제 절입 시각을 경계로 전환
- 월주: 12개 절(입춘·경칩·청명·입하·망종·소서·입추·백로·한로·입동·대설·소한)의 실제 절입 시각을 경계로 전환
- 일주: 60갑자 순환을 독립 계산하고 한국천문연구원 일진 자료와 golden test로 대조
- 시지: 시간 보정이 끝난 시각을 기준으로 자시 23:00~00:59부터 2시간 단위
- 십성: 일간과 다른 천간의 오행 생극 및 음양 관계로 결정
- 오행 숫자는 우선 '천간 4 + 지지 4의 표면 구성'으로만 표시하며 신강·신약 점수로 사용하지 않음
- 출생시간 미상은 시주를 만들지 않음

## 한국 법정 시각

`korea-time.mjs`는 JavaScript 런타임의 **IANA `Asia/Seoul` timezone database**를 사용합니다.
다만 런타임에 따라 1970년 이전 역사 데이터가 축약될 수 있으므로 **v0.1은 1970~2100년 한국 출생만 계산 지원 범위로 둡니다.** 1987~1988 서머타임처럼 1970년 이후의 법정 시각 변화는 timezone database를 통해 반영합니다.

1970년 이전 출생은 한국 표준시 변천과 당시 DST 자료를 별도 데이터셋으로 검증한 뒤 지원 범위를 넓힙니다.

입력한 현지 시각은 가능한 UTC instant를 역산하며:

- 1개 → 정상 시각
- 0개 → DST 전환 등으로 존재하지 않았던 시각
- 2개 → 시계를 되돌리며 두 번 존재한 시각

으로 구분합니다.

이 단계는 **법정 시각 정규화**일 뿐이며 출생지 경도·진태양시·균시차 보정과는 별도입니다.

## 절기 데이터

현재는 한국천문연구원(KASI)의 2026년 달력자료를 regression fixture로 넣었습니다.
2026년 입춘 02-04 05:02, 한로 10-08 15:29 같은 **분 단위 경계**가 테스트에 고정되어 있습니다.

전 연도 지원 시에는 특정 연도의 하드코딩을 확대하는 대신, 검증 가능한 절기 provider를 별도 모듈로 붙이고 공식 자료와 표본 대조합니다.

## 아직 정책으로 확정하지 않는 항목

- 23:00~23:59 일주 변경(자초/자정 경계)
- 출생지 경도에 따른 태양시 보정
- 균시차 적용
- 역사적 서머타임 경계에서 모호/존재하지 않는 입력의 사용자 처리 방식

이 항목들은 엔진 내부에서 몰래 결정하지 않고 명시적 정책으로 둡니다.


## 1970~2100 절기 provider

전 연도 절기 경계는 `astronomy-engine@2.1.19`의 `SearchSunLongitude`를 사용해 계산합니다.
입춘 315°, 경칩 345°, 청명 15°처럼 12개의 절(節)에 대응하는 태양의 겉보기 지심 황경 도달 시각을 직접 찾습니다.

이 provider는 KASI 2026 fixture의 13개 경계(전년 대설 carry-in 포함)와 자동 회귀 테스트로 대조합니다.
KASI 공개 시각과의 차이가 90초 이상이면 빌드를 실패시킵니다.

따라서 사주결의 1970~2100 지원은 '매년 비슷한 날짜를 추정'하는 방식이 아니라,
각 연도의 천문학적 절입 순간을 계산하는 방식입니다.
