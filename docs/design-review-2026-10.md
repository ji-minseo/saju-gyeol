# 사주결 디자인 개선 · 2026-10-06

## 검토한 서비스

- 사주몰 https://www.sajumol.com/ — 홈의 질문형 상품 안내, 무료 범위 고지, 실제 결과 예시, FAQ. 브라우저에서 홈 화면 확인.
- 율명 https://yul-myeong.com/ — 브랜드 소개, 명식 예시, 풀이 범위와 방법론 공개. 웹 페이지 콘텐츠 검토.
- 포스텔러 만세력 https://pro.forceteller.com/ — 명식 계산·오행 분석 중심의 도구 포지션. 공식 검색 결과와 서비스 설명 검토; 상세 화면 디자인은 평가하지 않음.

## 기존 화면의 문제

1. 넓은 입력 폼이 화면을 차지하지만 서비스의 가치와 읽을 수 있는 범위가 드러나지 않는다.
2. 진한 녹색, 강한 입체 그림자, 커서에 반응하는 폼 기울기가 정보 입력을 압도한다.
3. 반복적으로 추가된 CSS가 정렬·폭·색을 여러 번 덮어쓰며 유지보수를 어렵게 한다.
4. 계산 기준 페이지의 '엔진 연결 전' 설명이 실제 계산 구현과 다르다.
5. 무료 범위·시간 미상·음력·입력값 저장 여부를 시작 전에 확인하기 어렵다.

## 반영한 방향

- 데스크톱에서 브랜드 소개와 입력 폼을 한 화면에 배치. 모바일에서는 짧은 소개 다음에 입력 폼을 배치.
- 종이색 바탕, 먹빛 텍스트와 주 버튼, 살구색 선택 표시. 녹색의 큰 면적을 줄이고 오행 색은 데이터 구분에 사용.
- 한글 명조 계열 제목과 네 기둥을 형상화한 CSS 아트로 자체 브랜드 분위기 구축. 외부 이미지·폰트 요청 없이 표시.
- 폼은 고정된 위치에서 입력하고, 키보드 포커스와 선택 상태를 구분. 기존 날짜·시간·계산 기능 유지.
- 명식의 일주를 먹빛으로 강조하고 결과의 구조 데이터와 서술 해설을 구분.
- 제공 범위 및 FAQ 추가. 실제 구현에 맞춰 계산 기준 페이지 갱신.
- 등장과 결과 전환은 작은 이동과 투명도 변화만 사용하며 reduced-motion 설정 준수.
