PRIVACY POLICY

개인정보처리방침

사주결은 서비스 제공에 필요한 범위에서만 정보를 사용하고, 무료 결과는 서버에 저장하지 않는 것을 기본으로 합니다.

시행일 2026년 10월 15일

1. 개인정보처리자

지지마켓은 사주결 서비스에서 처리되는 개인정보에 대해 관련 법령에 따라 개인정보처리자의 책임을 부담합니다.

2. 처리하는 정보와 목적

무료 사주 계산
생년월일, 출생시간(선택), 성별(선택), 달력 기준, 일주 날짜 경계 설정. 사주 명식 계산 및 해석 제공을 위해 브라우저에서 사용하며 기본적으로 서버에 저장하지 않습니다.
최근 결과 저장
이용자가 직접 체크한 경우에만 출생정보와 설정을 현재 브라우저의 localStorage에 저장합니다. 이용자는 화면의 삭제 기능으로 언제든 지울 수 있습니다.
유료 정밀 리포트
생년월일, 출생시간, 성별, 날짜 경계 설정 및 결제 식별자. 결제 주문 검증과 맞춤형 리포트 생성에 사용합니다.
고객문의
이메일 주소와 문의 내용. 문의 확인과 답변을 위해 사용합니다.

3. 보유 및 이용기간

무료 사주 입력정보는 사주결 서버에 별도 데이터베이스로 저장하지 않습니다. 유료 리포트 MVP 역시 출생정보를 별도 고객 데이터베이스에 저장하지 않고, 결제 후 발급되는 서명된 접근 토큰을 통해 리포트를 다시 생성할 수 있도록 설계되어 있습니다. 접근 토큰의 기본 유효기간은 30일입니다. 다만 결제·계약·분쟁 처리에 필요한 거래기록은 관련 법령에서 정한 기간 동안 결제대행사 또는 사업자가 보관할 수 있습니다.

4. 외부 서비스 이용

PortOne / NHN KCP
유료 콘텐츠의 결제창 제공, 결제 승인·상태 확인, 결제 관련 처리에 사용됩니다. 카드번호 등 결제수단의 민감한 정보는 사주결이 직접 저장하지 않습니다.
Vercel
유료 결제 검증 API와 정밀 리포트 생성 서버의 호스팅에 사용됩니다.
GitHub Pages
사주결 웹사이트의 정적 파일 호스팅에 사용됩니다.

5. 브라우저 저장소와 쿠키

최근 결과 저장 기능은 쿠키가 아니라 이용자의 브라우저 localStorage를 사용하며, 사용자가 직접 선택한 경우에만 저장됩니다. 유료 결제 진행 중에는 주문·리포트 접근을 이어가기 위해 sessionStorage를 사용할 수 있습니다. 브라우저 설정 또는 사주결의 삭제 기능을 통해 저장정보를 지울 수 있습니다.

6. 이용자의 권리

이용자는 본인의 개인정보에 대해 열람, 정정, 삭제, 처리정지 등을 요청할 수 있습니다. 서버에 별도로 저장되지 않은 브라우저 로컬 정보는 이용자가 직접 삭제할 수 있습니다. 그 밖의 요청은 아래 이메일로 접수해 주세요.

7. 안전성 확보

유료 결제는 브라우저의 성공 응답만으로 판단하지 않고 서버에서 결제대행사의 결제 상태와 금액을 다시 검증합니다. 결제 API Secret과 리포트 서명키는 브라우저 코드에 포함하지 않고 서버 환경변수로 관리합니다.
